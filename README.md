AI Multi-Agent Development Team

A human-controlled AI software development team built using Telegram and Switch.

Overview

This project brings together nine specialized AI agents that collaborate to support the software development lifecycle. The human project owner coordinates the agents and makes final decisions.

Agent Architecture

Agent| Responsibility
Architect| Creates development plans and technical specifications
Arbiter| Independently reviews and validates plans
Forge| Implements approved development tasks
Probe| Tests implementations and reports bugs
Debugger| Investigates and fixes reported bugs
Critic| Reviews code quality and security
Refactor| Applies approved code improvements
Validator| Performs final application validation
Sentinel| Monitors workflow activity in read-only mode

Development Workflow

1. Architect prepares the development plan.
2. Arbiter independently reviews the plan.
3. The human owner authorizes implementation.
4. Forge implements the approved requirements.
5. Probe tests the implementation.
6. Debugger addresses confirmed bugs.
7. Critic reviews the code.
8. Refactor applies approved improvements.
9. Validator performs final validation.

Sentinel independently monitors the workflow throughout the process.

Demonstration Project

The team is being tested through development of a Task Management Web Application.

Planned features include:

- User authentication
- Task creation and management
- Priorities and deadlines
- Dashboard and task status tracking
- Soft deletion and task restoration

Safety and Security

- Human-controlled development workflow.
- Sentinel is strictly read-only.
- No paid service purchases without explicit authorization.
- Secrets and credentials must never be committed to the repository.

Project Status

The multi-agent team is configured and connected through Telegram and Switch. The demonstration application is under development.
